# 智能厨房助手 · PWA（产品本体）

这是**可安装的 Web App**，不是宣传官网。

- 官网（给所有人看的介绍页）→ 仓库里的 [`../website/`](../website/)
- 本目录 → 真正用的产品（库存 / 菜谱 / 推荐 / 计划）

依据 [designdoc_v2.md](../designdoc_v2.md)：单用户密码、PWA 主线。

---

## 怎么本地打开

PWA 的 Service Worker /「添加到主屏幕」需要通过 **http(s)** 访问（不要用 `file://` 双击打开）。

```bash
cd pwa
python3 -m http.server 5174
```

手机和电脑浏览器打开：

**http://本机局域网IP:5174/**  
（手机需与电脑同一 Wi‑Fi；本机可用 http://127.0.0.1:5174/）

默认密码：`kitchen2026`

## 怎么安装到手机主屏幕

### iPhone（Safari）

1. 用 Safari 打开上面的地址（不要用微信内置浏览器）
2. 点底部分享 → **添加到主屏幕**
3. 从主屏幕图标打开（全屏、可离线缓存静态资源）

### Android（Chrome）

1. Chrome 打开地址
2. 菜单 → **安装应用** / **添加到主屏幕**  
   或页面上的「安装 PWA」按钮（若浏览器弹出）

## 和官网、iOS 壳的关系

| | 用途 | 目录 |

| **官网** | 介绍产品，给非展会用户 / 任何人浏览 | `website/` |

官网 CTA 可以链到你部署后的 PWA 地址；两者分开部署更清晰。

---

## 部署建议

任意静态托管即可，例如：

- Cloudflare Pages / Netlify / GitHub Pages：把 `pwa/` 设为站点根目录
- 务必使用 **HTTPS**（安装与 SW 才稳定）

部署后把官网里的「打开应用」链接改成该 HTTPS 地址。

## 功能速览（当前脚手架）

- 密码登录（无注册）
- 库存：冷藏/冷冻/室外、临期横幅、手动添加、拍照/文字识别确认入库（演示规则）
- 菜谱：起步库、文字/链接导入骨架、加入计划、做完扣库存
- 推荐：食材 × 烹饪方式筛选，「已有/缺少」，缺少一键进清单
- 计划：从计划生成购物清单（需求 − 库存），勾选后入库

数据存在浏览器 `localStorage`，清站点数据会丢失。
